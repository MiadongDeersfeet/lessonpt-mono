# 모바일 교사 화면 설계 및 구현

기준: feature/render-deployment / ef13eb3. 작업: feature/mobile-teacher-ux (로컬 변경, 배포 안 함).

## 2단계 설계

- 기존 베이지/브라운 색상과 글꼴을 유지한다. `/`는 교사 `/login`으로 바로 연결한다. 로그인된 교사는 기존처럼 학생 목록으로 이동한다.
- 학생 전용 `/student/*`는 잠정 중단 안내와 교사 로그인 링크만 제공한다. 기존 링크를 방문해도 OTP나 포털 조회를 시작하지 않는다.
- 교사 학생 관리에서 이메일 입력/표시와 Portal 컬럼/접근설정 탭을 제거한다. 신규 학생 API에는 email:null, 기존 학생 편집에는 저장된 email을 그대로 전달한다. DB와 기존 API 필드는 삭제하지 않는다.
- 900px 이하 학생 목록은 카드로 표시한다. 이름 → 연락처/출강처 → 커리큘럼 → 진도/메모 → 학습관리/편집/삭제 순서. 900px 초과는 기존 표 형식을 유지한다.
- 목록에 이름·전화번호·출강처 검색을 추가한다. 학습관리 버튼은 학생 상세의 학습 탭을 바로 연다. 기본 이름 링크는 기본정보로 간다.
- 학생 입력창은 공통 Overlay의 포커스 관리/Escape/스크롤 잠금을 사용한다. 변경된 입력을 닫을 때 계속 입력/입력 버리기를 명확히 선택한다. 저장 실패 시 입력 유지, 제출 중 닫기 금지.

## 구현 범위

- 위 교사 중심 진입/목록/학생 폼을 구현했다. 목록의 Portal 요청을 없애 1+2N에서 1+N 요청으로 줄이고, 추가 조회 동시성을 최대 4개로 제한하며 각 결과를 바로 반영한다.
- 잘못된 tbody 직계 form을 셀 내부로 이동해 빠른 입력의 유효한 form 연결을 보존했다.
- 학생 상세와 커리큘럼 편집기는 lazy/Suspense로 분리한다. 로그인 코드는 즉시 사용할 수 있다.
- 서버 Security chain에 잠정 차단 필터를 넣었다. prod에서 LESSONPT_STUDENT_PORTAL_ENABLED 기본 false. 학생 OTP/포털 읽기와 신규 초대 생성을 503으로 차단한다. 로그아웃, 교사 학생 관리, 기존 접근 해제는 허용한다. 저장된 세션/자료/학생은 삭제하지 않는다.
- 비운영 프로파일의 기존 학생 테스트·개발은 기본 활성 상태를 유지한다. 재개하려면 백엔드 설정뿐 아니라 프론트엔드의 중단 경로도 명시적으로 되돌려야 한다.

## 검증 및 영향

운영 DB/Render API 대신 로컬 가상 데이터 서버로 브라우저 UI 검증. 실제 학생 생성/수정/삭제/업로드는 실행하지 않는다. 기존 비활성 학생 기능의 컴포넌트 테스트는 라우터에서 분리해 유지한다.

학생 목록/상세/라우터/공통 폼을 포함한 전체 프론트엔드 테스트, 타입 검사, production build와 서버 차단/교사 인증 테스트를 실행한다. 320×568, 375×667, 390×844, 430×932, 768×1024, 1440×900에서 목록 폭을 확인한다.

이번 변경은 최초 교사 중심 모바일 사용성 단위다. 나머지 legacy 삭제/배정 모달의 전면 통합, 과제 초안, 전역 네트워크 취소/재시도, CSS 전체 분리와 Lighthouse/실기기 성능 계측은 별도 작업으로 남긴다. 이들은 데이터 보존/쓰기 재시도 규칙과 범위를 더 정밀하게 정해야 하며 완료로 간주하지 않는다.

커밋/푸시/병합/배포하지 않았다. 특히 기존 main 워크플로는 OCI 배포를 실행하므로 로컬 검증 결과만으로 main에 병합하지 않는다.

## 최종 확인 결과 (2026-11-02)

- 프론트엔드 25파일/149개 테스트 통과, 타입 검사 통과, production build 성공. 빠른 입력 HTML nesting 경고 제거.
- 서버 StudentPortalAvailabilityFilterTest 11개와 실제 차단 설정을 포함한 TeacherAuthSecurityTest 5개, 합계 16개 통과. 외부 DB 통합 시험 아님.
- lint 오류 없음. 기존 context export 및 effect 상태 갱신 패턴 관련 경고 10개는 남아 있다.
- 초기 JS gzip 108.18KB → 91.77KB. 학생 상세/편집기 코드 분할과 학생 페이지 라우터 제거의 결과이며, Lighthouse 점수 개선 측정값은 아니다.
- 로컬 가상 데이터 6개 뷰포트에서 학생 목록의 document.scrollWidth가 clientWidth를 초과하지 않음. 이름/전화/출강처 검색, 학습관리 탭 직행, 학생 링크 중단 안내, 미저장 닫기 확인을 브라우저에서 검증.
- 실제 휴대폰 키보드/safe-area, 운영 저장/업로드, Oracle·OCI 접속, 실사용 성능은 미검증. 학생 서비스 차단은 배포 후 적용되며 현재 운영 사이트는 그대로다.
